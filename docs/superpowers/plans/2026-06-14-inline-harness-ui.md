# Inline Test2-Harness-UI (DBIx::Class) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Inline the Test2-Harness web UI into Test2-Harness2, following pre_ai_2.0 structure, converted to App::Yath2/Test2::Harness2 namespaces, retargeted to our facets, options on Getopt::Yath, with Perl + Playwright tests.

**Architecture:** Plack + Router::Simple + Text::Xslate web app over a DBIx::Class schema (5 drivers, SQLite default for ephemeral/tests). Faithful port of pre_ai_2.0 Perl + 1.0 `share/` assets. ORM access isolated behind Schema/ResultSet/Overlay for a later QuickORM swap.

**Tech Stack:** Perl (DBIx::Class, Plack, Router::Simple, Text::Xslate, Starman, DBIx::QuickDB, Getopt::Yath), SQLite/Pg/MySQL/MariaDB/Percona, Playwright (Node) for JS/CSS.

**Sources:**
- Perl structure: `reference/pre_ai_2.0/lib/App/Yath/{Server*,Schema*,Command/{server,db*,client*},Options/{DB,WebServer,Server,WebClient,Publish},Plugin/DB,Renderer/{DB,Server}}`
- Assets/demo/psgi: `/home/exodist/projects/Test2/Test2-Harness-UI/share`, `.../demo`, `.../share/psgi`
- Facet shapes: our 2.0d (`lib/Test2/Harness2`, captured real log)

**Conversion rules (apply to every ported file):**
1. `App::Yath::` → `App::Yath2::`; `Test2::Harness::` → `Test2::Harness2::` (package + use + require + string).
2. `require "App/Yath/Schema/..."` → `App/Yath2/Schema/...`; `dist_dir('Test2-Harness'|'Test2-Harness-UI')` → `'Test2-Harness2'`.
3. Keep `Test2::EventFacet::Binary` name.
4. `use v5.38` + signatures + HashBase + `croak` + `eval {...;1}` per STYLE_GUIDE where touching non-generated files. Generated driver classes are exempt (regenerated by tool).
5. Clean stale `Test2-Harness-UI` POD repo refs.
